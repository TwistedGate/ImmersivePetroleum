Энергия подается через два высоковольтных разъема на передней панели машины, а битум и вода - через два обозначенных входных отверстия на передней панели машины. Сернистое дизельное топливо выводится из оранжевого отверстия спереди, а нефтяной кокс - из двух бункеров под коксовыми барабанами.

Она строится, как показано на схеме и формируется ударом молота инженера по бетонному блоку в центре, рядом с редстоуновым инженерным блоком.<np>
Подача сигнала редстоуна на панель управления машины будет останавливать работу. Это поведение можно инвертировать с помощью Отвёртки.

Процесс коксования проходит в следующем образом:
Битум загружается в барабаны для коксования. После завершения загрузки барабаны нагреваются до нужной температуры, и битум превращается в нефтяной кокс и сернистое дизельное топливо.

Когда переработка завершена, из бочек сливают сернистое дизельное топливо и затем промывается водой для охлаждения перед повторной загрузкой битума.<np>
Процесса коксования начинается сразу после начала заполнения барабанов для коксования, на первом этапе цикла коксования может быть загружено больше битума. Как только начнутся фазы выпуска и промывки, больше битума нельзя будет загружать до завершения цикла.

Барабаны для коксования работают независимо: как только загружаемый в данный момент барабан для коксования заполнится битумом, битум будет загружен в другой барабан, если только этот барабан уже не работает.
