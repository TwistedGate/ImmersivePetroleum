Штанговый насос - многоблочная машина, выкачивает нефть из скважин созданых <link;immersivepetroleum:derrick;§o§nбуровой вышкой§r>.
Формируется ударом молота по тяжёлому инженерному блоку во втором слое.<np>
Штанговые насосы- это рабочие лошадки нефтедобычи, которые медленно, но стабильно добывают жидкость из своих скважин, поднимая ее через односторонний клапан, чтобы компенсировать недостаток давления в скважине. Скважины, в которых все еще сохраняется давление, преодолевают клапан насосного устройства и из них начинает поступать жидкость.

Для работы напорный патрубок должен располагаться непосредственно на устье скважины, чтобы клапанное устройство можно было опустить в устье скважины.<np>
Штанговый насос использует <config;i;pumpjack_consumption> Flux/t для добычи <config;i;pumpjack_speed> mB/t нефти. Полученная нефть автоматически выталкивается с боковых портов, помеченных оранжевыми точками.

Средних размеров месторождение будет исчерпано примерно за <config;i;pumpjack_days> дней. Добавление большего количества штанговых насосов ускорит этот процесс.

Подача сигнала редстоуна на панель управления машины, будет останавливать работу. Это поведение можно инвертировать с помощью Отвёртк
