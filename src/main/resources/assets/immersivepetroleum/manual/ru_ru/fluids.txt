Нефтепродукты
По крайней мере, это не Гречтек
<&crude>
Сырая нефть - это липкая черная субстанция, которая просачивается из <link;immersivepetroleum:reservoir;§n§oместорождений§r> в мир. Это базовый ресурс, из которое является сырьём для всех остальных видов нефтипродуктов и он необходим инженеру-нефтехимику в его профессиональной деятельности.

Сырая нефть может быть отделена в <link;immersivepetroleum:distillationtower;§n§oректификационной колонне§r> после ее извлечения из земли.
<&lubricant>
Смазка - это самая тяжелая фракция, которая может быть немедленно извлечена из <link;immersivepetroleum:fluids;§n§oнефти§r;crude>, и её лучше всего использовать для увеличения скорости работы машин за счет их смазки.  Его можно перерабатывать в  <link;immersivepetroleum:fluids;§n§oпарафин§r;paraffin>.

Её можно сжечь в газовом факеле или переработать в <link;immersivepetroleum:fluids;§n§oсернистый дизель§r;diesel> если это не бесполезно.
<&diesel>
Дизель и сернистый дизель являются наиболее востребованными видами топлива для инженеров-нефтехимиков, и их можно использовать в <link;immersiveengineering:diesel_generator;§n§oдизельном генераторе§r> для массового производства электроэнергии.

Сернистый дизель может быть использован в качестве простого источника серы и является второй по массе фракцией, которую можно перегонять из <link;immersivepetroleum:fluids;§n§oнефти§r;crude>.
<&kerosene>
Керосин - это среднее топливо, используемое в <link;immersiveengineering:diesel_generator;§n§oдизельном генераторе§r> для массового производства электроэнергии.  Он может быть разделен на <link;immersivepetroleum:fluids;§n§oлигроин§r;naphtha> и <link;immersivepetroleum:fluids;§n§oбензин§r;gasoline>.

Поскольку керосин является более легкой фракцией, чем <link;immersivepetroleum:fluids;§n§oдизель§r;diesel>, он не накапливает серу и не нуждается в десульфурации.
<&naphtha>
Лигроин - это летучее легкое топливо, которое можно использовать в <link;immersivepetroleum:portablegenerator;§n§oпереносном генераторе§r> или <link;immersivepetroleum:speedboat;§n§oмоторной лодке§r>, и также легчайшая фракция <link;immersivepetroleum:fluids;§n§oнефти§r;crude>.

Его летучесть можно регулировать, смешивая с бензиновыми присадками для получения <link;immersivepetroleum:fluids;§n§oбензина§r;gasoline>.

Лигроин является химическим сырьем для производства пластмасс и используется для производства<link;immersiveengineering:plastic;§n§oфенолоной смолы§r> из <link;immersivepetroleum:fluids;§n§oпродуктов крекинга§r;petroleum_gas>.
<&bitumen>
Битум - это темное, липкое твердое вещество, которое может быть использовано в качестве искусственного вяжущего для бетона, при изготовлении <link;immersivepetroleum:asphalt;§n§oасфалтобетона§r>, или подвергнуто пиролизу для получения  <link;immersivepetroleum:fluids;§n§oнефтяного кокса§r;petroleum_coke>.

Битум получаются как побочный продукт ректификации<link;immersivepetroleum:fluids;§n§ocrude oil§r;crude> at a slow rate.
<&petroleum_gas>
Нефтяной газ не поддается немедленной перегонке из сырой нефти, это более легкое сырье должно быть подвергнуто крекингу из <link;immersivepetroleum:fluids;§n§oлигроина§r;naphtha>.

Нефтяной газ нельзя использовать в генераторах из-за его газообразной природы. Вместо этого его можно использовать в качестве химического сырья для <link;immersiveengineering:plastic;§n§oфенолоной смолы§r>.
<&gasoline>
Бензин - это высококачественное легкое топливо, подходящее для <link;immersivepetroleum:portablegenerator;§n§oпереносного генератора§r> или <link;immersivepetroleum:speedboat;§n§oмоторной лодке§r>, а также может использоваться в синтезе <link;immersivepetroleum:fluids;§n§oнапалма§r;napalm>.

Он обладает пониженной волатильностью и более высокой эффективностью в <link;immersivepetroleum:portablegenerator;§n§oпереносном генераторе§r>. Бензин получают путем смешивания бензола, который получают из <link;immersivepetroleum:fluids;§n§oкеросина§r;kerosene> и <link;immersivepetroleum:fluids;§n§oлигроинаa§r;naphtha> в <link;immersiveengineering:refinery;§n§oочистительном заводе§r>.
<&napalm>
Напалм является чрезвычайно легковоспламеняющимся веществом, которое может быть приготовлено в <link;mixer;§n§oсмесителе§r> из <link;immersivepetroleum:fluids;§n§oбензина§r;gasoline> и алюминиего порошка. От него мало проку, кроме разрушения; когда поджигают напалм, огонь почти мгновенно распространяется по его поверхности, что позволяет быстро вырубать леса. Кроме того, он может служить в качестве очень эффективного топлива для <link;chemthrower;§n§oхимического распылителя§r>.
<&paraffin>
Парафин - это твердое вещество, похожее на воск, которое можно использовать в качестве искусственного заменителя пчелиного воска при изготовлении свечей или для вощения меди.

Парафин образуется в результате депарафинизации <link;immersivepetroleum:fluids;§n§oсмазки§r;lubricant> при высоком давлении с малой скорости.
<&petroleum_coke>
Нефтяной кокс - это аллотроп углерода высокой чистоты, эквивалентный угольному коксу. Его можно использовать для выплавки стали или прессовать в <link;immersiveengineering:graphite;§n§oВОПГ§r>.

Нефтяной кокс образуется в результате коксования при высокой температуре  <link;immersivepetroleum:fluids;§n§oбитума§r;bitumen>.
